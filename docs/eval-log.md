### 首轮观察

1. **「错得安静」零发生**：D2 用了成交价、C3/D3 去重了订单、D4 未知组出现 —— 三个招牌陷阱全部躲过，guard + lint + prompt 的口径约束在真实模型上生效。
2. **真失败模式只有两种**：① 输出纪律（C3 的中文别名列）；② 拒答校准（E4 该澄清不澄清）。第 4 周优化直接对这两个打。
3. **自愈循环几乎未被触发**（平均 1.10 次尝试）—— 优化重点在「一次写对」，不在「重试更聪明」。
4. **评测体系本身也被基线检验了**：比对器列投影缺陷、gold F1 重名缺陷都在首轮暴露 —— 这正是「先跑基线再优化」的价值。
