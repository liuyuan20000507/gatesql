# ADR-011 · 鉴权只做单口令 JWT

**背景**：公网部署要防 API key 被刷爆。

**决策**：单口令 + `jose` 签 httpOnly cookie + middleware 拦截 + IP 限流 + 日预算（超限降级 replay）。

**关键问题**：真实目标只有一个——别让 key 被刷穿。十几行代码完全达成。Auth.js + OAuth 是几天样板配置换**零简历价值**。

**代价**：没有多用户/权限体系——与「不接用户自己的数据库」定位一致，不是缺陷。

**加分点**：「预算耗尽降级 replay 而不是报 500」保证面试官任何时候打开链接都有东西看。
