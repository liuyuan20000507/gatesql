# ADR-021 · 时间窗口整体越过数据水位 → 提前拒答

**背景**：问「2027 年 1 月的销售额」，旧路径要花 1 次 LLM 调用 + 执行 + 空集归因探针，最后才说「范围内没数据」。

**决策**：步骤 1 时间归一后，若 `resolution.from > asOf`（窗口整体在数据水位后）→ 步骤 2.6 直接拒答，0 次模型调用。

**关键问题**：**系统在步骤 1 结束时就已经知道答案了**——问题窗口和数据水位不相交是纯代码可判定的，跑 LLM 只是绕路。且拒答理由更精确：「你问的时段在数据覆盖范围之外」（旧路径给的是「放宽时间范围后可见 N 行」的归因，间接）。

**边界（刻意只做一半）**：只拦「整体在后」。**部分重叠**（近 30 天跨过水位线）照常执行，由步骤 8 出「末端不完整」标记——因为部分重叠的数据仍有价值，而「窗口早于数据起点」需要另查 MIN(created_at)，留作后续。

**实测**：2027 题 / E5 均 llmCalls=0、理由精确；B4 部分重叠不受影响。评测 --ci 无回归。
