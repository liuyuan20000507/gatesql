# ADR-017 · 口径回执只翻译规则表枚举到的谓词形态

**背景**：回执卡是「数字凭什么可信」的证据，自然想翻译得越多越好。

**决策**：只翻译规则表枚举到的形态（R1 的 status='已完成' + 时间范围），lint 认不出的等价写法（`status <> '已取消'`）宁可整行不出现，也绝不硬编一句话。

**关键问题**：回执的价值在「模型不可见、代码机械生成」——一旦为了覆盖率让模型参与翻译或硬编码模糊措辞，**卡片就结构性地可能撒谎**，「已核验」的可信度跟着崩。语义修正实录：无金额聚合的查询（纯计数）没有口径声明义务，不算「翻译不全」——曾把这类查询误降级未核验，已修。

**代价**：覆盖率受限，部分合法写法拿不到完整回执。对冲：这类查询如实落「未核验」+ 说明，宁降级不撒谎。
