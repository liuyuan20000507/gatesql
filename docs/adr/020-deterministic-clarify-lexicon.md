# ADR-020 · 口径歧义澄清用确定性词典，不用模型判断

**背景**：「利润率」「复购率」等词有多种合理口径，模型自己不会主动澄清（4 轮实验证明）。

**决策**：确定性关键词词典（keywords 命中 + disambiguators 未点明 → 拒答 + 固定澄清选项）；多轮澄清 = 选项话术（必含 disambiguator）拼回问题自动重问。

**关键问题**：**模型判断「该不该澄清」本身是不确定的**——同一道题可能这次澄清下次瞎算。词典让「该澄清」变成确定性判决，且澄清选项是人工审定的（净利口径那条甚至写明「选了也算不出」）。

**代价**：词条覆盖有限、维护有成本。教训实录：新增词条曾误伤评测题 C3/D5（关键词命中但题面自带口径说明）——**disambiguators 必须对评测题面实测**，词条变更必须跑全量 replay（正是这次事故催生了 CI 门禁前置自查）。

**触发重估**：歧义词大量涌现（>20 条）时，可评估「模型初筛 + 词典终审」的混合模式——但仍须确定性兜底。
