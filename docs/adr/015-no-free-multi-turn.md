# ADR-015 · 不做自由多轮追问（会话化押后）

**背景**：取数产品的自然终局是「那上个月呢？」这种指代追问。

**决策**：只做**一键澄清**（歧义拒答 → 点选项 → 原问题 + 口径话术自动重问）；自由多轮会话押后。

**关键问题**：多轮 = 有状态 = 同一题两次跑出不同结果（上下文里带了上一问），**摧毁评测可复现性**——与向量检索同级别的风险。且 `/api/chat` 契约第一天就预留了 `conversationId`（恒传 null），真做是「填坑」不是「改契约」。

**如果做**：① conversations 表 + runs 外键；② loop 开头注入会话上下文；③ 前端聊天线程；④ **另起多轮题集**（判分标准：是否正确消解指代），与单轮 30 题并列互不污染。

**触发条件**：出现真实追问需求，或作品集要展示会话化能力——但必须连评测扩展一起做。

**代价**：单轮定位少一块「类 ChatGPT 体验」。对冲：一键澄清覆盖了最高频的追问场景。
