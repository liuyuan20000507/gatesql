# ADR-023 · 预算耗尽降级 replay，而不是报 500

**背景**：live 模式花真钱，日预算（DAILY_BUDGET_CNY）超了怎么办。

**决策**：`applyBudget`——预算 ≥0 且今日已花 ≥ 预算 → live/record **强制降级 replay**，哪怕显式设了 LLM_MODE=live（降级强于显式模式，否则「调 0 再提问」失去意义）；-1 为不限。

**关键问题**：**「预算耗尽报 500」等于把内部账本问题转嫁给用户**——而 replay 模式能让面试官任何时候打开链接都有东西看。降级是「有损但可用」，500 是「无损但不可用」——取数产品选前者。

**现状注记**：今日花费恒 0（token 计价 P2 未实现），budget=0 是唯一触发路径；计价落地后同一函数自动覆盖「部分超支」，无需改代码。
