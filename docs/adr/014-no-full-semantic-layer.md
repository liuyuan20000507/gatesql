# ADR-014 · 不做完整语义层

**背景**：「口径由代码保证」的终极形态是 QueryPlan IR + 确定性 SQL 编译器。

**决策**：只做 8 条口径规则 + AST 谓词到达性检查。

**关键问题**：完整语义层通向 Cube.js 克隆。4 张表的 join 路径写死十几行，通用求解器几周且面试零加分——面试官想听「哪些约束该代码保证、哪些交给模型」，不是「我实现了路径求解」。8 条规则拿走约 80% 叙事，成本 3-4 天而非 3 周。

**代价**：覆盖不到的口径形态只能落「未核验」——三态输出本来就承认「有些答案我不敢打包票」。剩余 20% 的做法写进 backlog。

**隐蔽失败模式**：语义层滑坡两周，第 6 周拿不到准确率曲线——而那条曲线是整个项目的全部简历价值。
