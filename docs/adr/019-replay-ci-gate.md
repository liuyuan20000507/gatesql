# ADR-019 · CI 门禁用 replay，不用 live

**背景**：CI 跑评测可以用真模型（live）也可以用 cassette 回放（replay）。

**决策**：CI 门禁强制 replay（`--ci` 旗标内置强制），零密钥零花费。

**关键问题**：门禁的全部价值建立在等式「**红灯 = 你的改动坏了**」上。live 的模型是非确定的——同一个 prompt 两次跑出不同结果，红灯可能是模型抽风（假警报），绿灯可能掩盖真回归（漏检）——**门禁两个方向同时失效**。replay 把模型冻成常量后，唯一变量就是你的代码改动，等式才成立。

**前提**：6C 对齐抽查 10/10 证明 replay ≈ live（结果等价），所以确定性替身是忠实的。工具 `scripts/spot-check.ts` 随时可复检。

**代价**：模型升级/提示词改动的效果要靠手工 record 轮重录才能进 CI 基线——这是刻意的：改基线必须是显式提交，不能被静默漂移污染。
